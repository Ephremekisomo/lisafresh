# Lisa Fresh Fair — Site vitrine

Ce dépôt contient un site statique de démonstration pour **Lisa Fresh Fair**, une entreprise vendant des lotions capillaires.

## Contenu
- `index.html` — page principale
- `assets/css/styles.css` — styles
- `assets/js/script.js` — interactions simples
- `assets/images/placeholder.svg` — image de remplacement (logo / photo)
- `assets/images/Produits/*-sm.jpg` / `*-md.jpg` / `*-md.webp` — versions optimisées générées (via `npm run optimize-images`)

## Aperçu
Ouvrir `index.html` dans votre navigateur ou utiliser l'extension **Live Server** de VS Code pour un rechargement automatique.

Pour optimiser les images localement, installez les dépendances puis lancez :

```bash
npm i
npm run optimize-images
```
